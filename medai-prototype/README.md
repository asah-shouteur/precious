# MEDAI Prototype

Lightweight React + TypeScript prototype showcasing Patient Dashboard and AI Assessment screens for the MEDAI project.

Run locally:

```bash
cd medai-prototype
npm install
npm run dev
```

This repo is a minimal, static prototype intended for design/demo purposes. It includes design tokens, components, sample data and two primary screens: Patient Dashboard and AI Assessment.
MEDAI — Design Prototype
=========================

Lightweight static prototype for MEDAI UI/UX: design tokens, components and two responsive screens (Patient Dashboard and AI Assessment).

Open files in a browser to view the mockups:

- index.html (Landing / overview)
- pages/patient-dashboard.html
- pages/ai-assessment.html

Recommended: open `index.html` in your browser (double-click or use a local static server).

To serve locally (optional):

```bash
# using Python 3
python3 -m http.server 5173
# then visit http://localhost:5173/
```

Design assets folder: `styles/` contains color tokens and component CSS.
