# MEDAI Design System (summary)

This file summarizes tokens, components and states used in the static prototype.

Colors
- Primary: #4B2E8E
- Surface: #F5F3FB
- Muted border: #E6E9EE
- Charcoal: #2B2B2F
- Status: Green #22A55A, Amber #F59E0B, Red #EF4444, Blue #3B82F6

Typography
- Inter — 14px body, 16px default, headings 20–34px

Spacing & radius
- Spacing scale: 4 / 8 / 12 / 16 / 24 / 32 / 40 / 64
- Card radius: 12px

Components
- Topbar, Sidebar, Cards, KPI cards, Metric cards, Device cards, Buttons (Primary / Ghost / Danger), Forms (inputs, selects), Tabs, Modal, Alerts, Timeline.

States & UX
- Loading: skeleton blocks
- Processing: progress indicator with message
- Success / Error / Warning banners
- Empty states with guidance

Accessibility
- WCAG AA color contrast aimed for in text vs background
- Focus outlines, aria-friendly labels recommended in implementation

Export
- CSS tokens are in `styles/styles.css`.
